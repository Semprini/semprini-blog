# The Big Game (1992) (Formerly OWG - One Week Game)

![the big game.png](https://s3.ap-southeast-2.amazonaws.com/semprini.me/media/images/the_big_game.2e16d0ba.fill-800x240.png)

This is just a demo of a game that we never finished back in the early 1990s. I can't remember how to play, but I do recall that you can swap ships, there was a cheat to get any weapon, you can talk to people in huts and use the teleporters somehow.
