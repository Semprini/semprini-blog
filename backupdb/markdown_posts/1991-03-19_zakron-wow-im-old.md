# Zakron (1991) - Wow, I'm old

![Commodore Disk User 1991.PNG](https://s3.ap-southeast-2.amazonaws.com/semprini.me/media/images/Commodore_Disk_User_1991.2e16d0ba.fill-800x240.png)

Amazing what you can find on the internet. I made this in high school. Back in the days before the world wide web when magazines came with floppy disks aka Sneakernet.

Written in assembler language for MOS 6502 processor.

Magazine: [Commodore DiskUser Issue\_29 1991 Mar](https://ia802809.us.archive.org/30/items/commodore-diskuser-29/Commodore_DiskUser_Issue_29_1991_Mar.pdf)
