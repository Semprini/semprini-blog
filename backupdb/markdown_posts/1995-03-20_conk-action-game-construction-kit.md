# CONK (1995) - Action Game Construction Kit

We started this construction kit but sadly Commodore died before we finished.

It has Bonk - the map editor:

![bonk.png](https://s3.ap-southeast-2.amazonaws.com/semprini.me/media/images/bonk.width-500.png)

Gonk - the sprite editor

![gonk.png](https://s3.ap-southeast-2.amazonaws.com/semprini.me/media/images/gonk.width-500.png)

Zonk - the action editor

![zonk.png](https://s3.ap-southeast-2.amazonaws.com/semprini.me/media/images/zonk.width-500.png)

And Ponk which is the game run-time engine. [Here's a zip of Conk](/documents/14/conk.zip) with a few sample games including [Blast Crap Out Of Anything That Moves (1996)](./1996-03-20_blast-crap-out-anything-moves.md).

To run any of the games, I use WinUAE as my Amiga emulator. Once I have a machine set up and the zip file unzipped into the Amiga's HD, then I use an AmigaShell:

For Blast, cd into the Blast folder where the Blast.game file is and run:

/Ponk/Ponk Blast.game

Or cd into the ConkDemo folder and run:

/Ponk/Ponk Spambo.game
